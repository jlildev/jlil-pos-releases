# Jlil POS — التنزيلات

**أحدث إصدار:** <https://github.com/jlildev/jlil-pos-releases/releases/latest>

## التثبيت

1. نزّل ملف `...-setup.exe` من صفحة الإصدار.
2. شغّله، وإن ظهر تحذير SmartScreen اختر **More info → Run anyway**.
3. اتبع خطوات المثبّت.

## التحقق من الملف

بجانب كل مثبّت ملف `.sha256` يحتوي البصمة. على Windows:

```powershell
Get-FileHash "Jlil.POS_1.2.0_x64-setup.exe" -Algorithm SHA256
```
